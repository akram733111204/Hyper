# تقرير التحقق المحلي — نسخة الركن 0.2.0

تاريخ إعداد الملفات: 3 نوفمبر 2026.

## ما اختُبر فعليًا

- تمت ترجمة **جميع ملفات وحدة `core`** بمترجم Kotlin المحلي بواسطة `scripts/test-core-local.sh`.
- اجتازت اختبارات Smoke الخاصة بالبحث العربي والباركود، وتحليل تواريخ الإنتاج والانتهاء، ومعالجة الشهر والسنة، وتحويل الكراتين إلى قطع.
- نجح اختبار كتابة ملف XLSX داخلي ثم قراءته مع الحفاظ على الاسم العربي والأصفار في أول الباركود والتشغيلات والملاحظات.
- **كتالوج المنتجات:** قراءة نموذج Excel ذي الأوراق الأربع المُضمّن في التطبيق؛ تصدير وقراءة `ProductCatalog` و`BarcodeAliases`؛ فحص الباركود البديل؛ دمج آمن مستقل عن بيانات الصلاحية؛ استيراد نفس الملف مرتين دون تكرار؛ رفض التعارض افتراضيًا؛ وتحديث مرجعي صريح عندما يسمح المستخدم.
- تم اختبار البحث العربي على منتجات الكتالوج بالعبارة «شاى الربيع».
- **الترقية:** قراءة ملف Excel حقيقي مكتوب بالنسخة السابقة `schema=1`، والتحقق من الحفاظ على الباركود والتاريخ والملاحظات، وكتابة صيغة `schema=2` الجديدة.
- نجح التحقق النحوي لخادم Node اختياري باستخدام `node --check server/server.mjs`.

التحقق قابل لإعادة التشغيل:

```bash
bash scripts/test-core-local.sh
```

## ما لم يتم اختباره

- **لم يتم تشغيل Android Gradle أو بناء APK** في هذه البيئة لعدم توفر Android SDK/Gradle والاعتماديات اللازمة للبناء.
- **لم تُختبر الشاشات الجديدة على Android فعلي**؛ يجب تشغيل GitHub Actions، ومعالجة أي أخطاء تجميع محتملة، ثم تجربة القائمة المنسدلة والاستيراد وبحث الكتالوج والماسح على الجهاز.
- لم يُختبر تكامل SFDA أو GS1 رسميًا لعدم وجود تصريح API فعلي وإعدادات اتصال مؤسسية.
- لم تُجر اختبارات الضغط لعشرات الآلاف من المنتجات أو انقطاع الطاقة أو الملفات الضارة بمقياس مؤسسي.
- التعرف الآلي على التواريخ العربية والطباعات التالفة، والإشعارات الخارجية، ما زالت بحدود النسخة السابقة الموضحة في المستندات.

**الاستنتاج:** نواة البيانات الجديدة اجتازت اختبارًا محليًا قابلًا للتكرار؛ جاهزية APK والإنتاج لا تزال غير مثبتة.
