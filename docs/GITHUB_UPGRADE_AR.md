# تحديث مشروع GitHub إلى الركن 0.3.0

هذه نسخة **ملفات مصدر**، وليست APK جاهزًا. احتفظ بنسخة من الإصدار السابق أو أنشئ فرعًا باسم `backup-v0.2.0` قبل استبدال الملفات.

## التحديث باستخدام Git على الكمبيوتر (الطريقة الأكثر موثوقية)

1. نزّل أرشيف المشروع الجديد وفك ضغطه. يجب أن تجد جذر المشروع بداخله `app/`, `core/`, `server/`, `.github/` وملف `build.gradle.kts`.
2. إذا كان لديك المشروع القديم مستنسخًا محليًا، انسخ ملفات ومجلدات النسخة الجديدة إلى **جذر المستودع القديم** مع الاستبدال؛ راجع قائمة الملفات المحذوفة ولا ترفع كلمات مرور.
3. نفذ من جذر المستودع:

```bash
git status
git add -A
git commit -m "Upgrade Rukn Expiry to 0.3.0 with Voice AI"
git push origin main
```

## التحديث من واجهة GitHub فقط

- ارفع **محتويات** مجلد `rukn-expiry-v3` وليس ملف ZIP مغلقًا. لا تضع مجلدًا إضافيًا حول المشروع داخل المستودع.
- راجع خصوصًا وجود `.github/workflows/android.yml` في جذر المستودع. إذا لم يرفع متصفحك المجلد المخفي، أنشئه من `Add file → Create new file` وألصق نص ملف workflow الموجود في الأرشيف.
- احذف الملفات القديمة التي لم تعد مطلوبة أو تعارض الجديدة بعد أخذ نسخة. **لا تحذف مجلد `.github`**.
- من **Actions** افتح `Android CI — بناء وتجربة تطبيق الركن`، وشغّل البناء على الفرع `main`. يجب اجتياز اختبارات `:core:test` وبناء `:app:assembleDebug`.
- نجاح رفع الكود لا يثبت نجاح APK. إذا فشل البناء افتح سجل المهمة الفاشلة وأصلح أول خطأ تجميع حقيقي، ثم أعد التشغيل.

## الاختبار بعد تثبيت APK التجريبي

1. مسح الباركود والتعرف على منتج من Excel أو إضافته يدويًا.
2. «التالي» ثم منح إذن الميكروفون والتحدث بالعربية بتواريخ وكمية ورف.
3. التحقق من عرض النص الجزئي، والتغييرات المقترحة، ثم تطبيقها ومراجعة التاريخ في الاستمارة.
4. تجربة «غير شهر الانتهاء»، «احذف الملاحظات»، «زود الكمية خمس حبات» مع منع اختلاف الوحدات.
5. حفظ منتج، إغلاق التطبيق، إعادة فتحه، وفحص بقاء البيانات في XLSX.
6. تجربة البحث الصوتي عن شاي الربيع.
7. إذا اخترت السحابة، تأكد أولًا من إعداد الخادم والرمز والموافقة، وافصل الإنترنت عمدًا للتحقق من الفشل الآمن.

**تنبيه:** المستودع الذي يحتوي على شعار الشركة وكودها يفضّل أن يكون خاصًا (Private). ولا ترفع مفاتيح OpenAI أو رموز الخادم أو أي بيانات عملاء.
